Bug Hunt

Activity Provider para a Inven!RA. Nesta fase, os serviços respondem com dados de exemplo.

Serviços

  • GET /config: página de configuração
  • GET /json-params: parâmetros da configuração
  • GET /deploy?activityID=teste123: deploy de uma instância
  • POST /analytics: analíticas (abre a página de teste)
  • GET /analytics-list: lista de analíticas
